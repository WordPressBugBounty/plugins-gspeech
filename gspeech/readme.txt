### Text to Speech WordPress Plugin - GSpeech TTS

[GSpeech](https://gspeech.io) is an advanced __WordPress Text to Speech plugin__ that converts WordPress posts, pages, and WooCommerce product descriptions into natural-sounding __text-to-audio narration__ in __98 languages__. It automatically adds a modern __WordPress audio player__ to your website, allowing visitors to __listen to articles, blog posts, and product content__ instead of just reading them.

GSpeech works as a __lightweight WordPress text-to-speech bridge__ between your website and the GSpeech Cloud. Instead of generating audio on your WordPress server, GSpeech handles voice synthesis, audio storage, smart caching, and playback delivery in the cloud, helping your site stay fast while visitors listen to your content.

== Installation ==

1. Go to the WordPress plugin installer and search for __"GSpeech"__.
2. Install the plugin or upload the plugin file downloaded from WordPress.org.
3. Activate the plugin through the __Plugins__ menu in WordPress.
4. After activation, you will see the __GSpeech__ menu in your WordPress admin panel.
5. Click __Activate Cloud Console__ (one click). The required widgets will be created automatically.
6. Insert a Full Page Player using the shortcode: __[gspeech]__.
7. Insert a Button Player using the shortcode: __[gspeech-button]__.
8. Insert a Circle Player using the shortcode: __[gspeech-circle]__.
9. The __Read Highlighted Text (RHT) Player__ will be activated automatically.

__Your generated audio stays available.__ GSpeech does not delete previously generated audio files when your plan changes, including a change to the Free plan.

Your audio remains securely stored in the GSpeech Cloud and available in your dashboard for playback and download. You can download your generated .mp3 files from the dashboard at any time.

Yes. __Back-Catalog Cloud Generation__ covers posts from past years the same way as new ones. Audio is generated in the GSpeech Cloud when a visitor first requests playback, so you do not pre-generate the entire archive or spend characters on old articles nobody listens to.

= 👉 How to insert a player in a post, page, or article? =
After activating the __Cloud Console__, the required widgets are created automatically.

__Shortcodes:__
1. Full Page Player – __[gspeech]__
2. Button Player – __[gspeech-button]__
3. Circle Player – __[gspeech-circle]__
4. Inline player – __{gspeech id=ID}text to speech{/gspeech}__ (ID = widget ID)
5. GSpeech Player block - Full, Button, or Circle

To edit player settings:  
Go to __WP-Admin → GSpeech → Cloud Console → Widgets__.

To automatically add players on multiple pages:  
Publish the __Multi-Page Widget__ inside the Widgets section.

You can also [contact us](https://gspeech.io/contact-us) and we will help configure it for your website.

= 👉 What is the Read Highlighted Text (RHT) Player? =
The __RHT Player__ improves accessibility by allowing visitors to listen to any selected text on your website.

It activates automatically when the plugin and __Cloud Console__ are enabled.

Configuration:  
Go to __WP-Admin → GSpeech → Cloud Console → Widgets → RHT Player__.

Available views:
• __View 1__ – Circle player with timeline, volume, and speed controls  
• __View 2 & 3__ (commercial plans) – include translation and text panels

See the [Screenshots Section](https://wordpress.org/plugins/gspeech/#screenshots) for examples.

= 👉 Can I customize how GSpeech pronounces brand names and technical terms? =
Yes. GSpeech commercial plans include __Smart Pronunciation Aliases__, allowing you to customize how brand names, acronyms, personal names, abbreviations, and technical terminology are spoken.

Aliases can be applied globally, to a language, or to a specific locale.

Examples:

* `AI:Artificial Intelligence:en`
* `Generation Z:Generation Zee:en-US`
* `Generation Z:Generation Zed:en-GB`

The original website text remains unchanged. Only the text prepared for speech generation is adjusted.

Learn more in the [GSpeech pronunciation aliases guide](https://gspeech.io/blog/language-based-pronunciation-aliases).

= 👉 How to use Welcome Messages? =
After activating the __Cloud Console__, the Welcome Message widget is created but disabled by default.

To enable it:  
Go to __WP-Admin → GSpeech → Cloud Console → Widgets → Welcome Message__ and set __Status = Published__.

You can customize the message text, restrict it to specific pages using __Allowed URLs__, or configure it to play only once per session.
